X-agent local pipeline

X-agent collects information about audio plugins, instruments, and other music products, checks sources, and prepares content for a product catalog.

How YouTube is used

The application finds public product reviews and demonstrations. Google authorization is used to retrieve the list of available caption tracks and select an appropriate language. Caption text may be used to assess a video's usefulness and extract facts supported by the source.

Account access

Google's youtube.force-ssl permission is required to request the caption track list. X-agent uses this permission to read caption metadata. The application does not upload or delete videos, or modify channels, comments, subscriptions, or playlists.

Using the application

X-agent runs locally on the operator's computer. This website provides application information and describes how data is handled. Publishing prepared content to the catalog requires a separate action by the operator.
